# 🤖 Robot Track Timer (Time Trial)

ระบบจับเวลาการแข่งขันหุ่นยนต์เดินตามเส้นประเภท **Time Trial (วิ่งทีละตัว)** สิ้นสุดการวิ่งแบบครบรอบ (จุดเริ่มต้นและเส้นชัยเป็นจุดเดียวกัน) ด้วยความแม่นยำสูงระดับไมโครวินาที ควบคุมด้วยบอร์ด Arduino Uno และแสดงผลผ่านหน้าจอคอมพิวเตอร์ (Full Screen GUI) รองรับการใช้งานทั้งบน Windows และ macOS

## ⚡ คุณสมบัติของระบบ (Features)

*   **High Precision Timing:** ใช้ Hardware Timer 1 (16-bit) ของ ATmega328P โดยตรง ไม่ผ่านฟังก์ชัน `millis()` ทำให้ไม่มีปัญหาปัดเศษสะสม แม่นยำระดับไมโครวินาที
*   **Real-time Refresh Rate:** ส่งข้อมูลเวลาปัจจุบันแสดงผลบนหน้าจอทุกๆ 50 มิลลิวินาที (20 Hz) ตัวเลขวิ่งไหลลื่น สมจริง ไม่หน่วงบอร์ด
*   **Immersive Full Screen GUI:** หน้าจอแสดงผลขนาดใหญ่ยักษ์โหมดเต็มจอ (Fullscreen) มองเห็นชัดเจนจากระยะไกล เหมาะสำหรับเปิดโชว์บนโปรเจกเตอร์ในสนามแข่ง (กด `Esc` เพื่อ เปิด/ปิด เต็มจอ)
*   **Smart Debounce:** มีระบบป้องกันสัญญาณรบกวนจากการที่ท้ายหุ่นยนต์หรือเงาตัดผ่านเซนเซอร์ซ้ำซ้อนขณะออกตัว

## 🛠️ อุปกรณ์ที่ใช้งาน (Hardware Requirements)

1.  **Microcontroller:** บอร์ด Arduino Uno R3 (หรือรุ่นที่ใช้ชิป ATmega328P)
2.  **Sensor:** เซนเซอร์อินฟราเรดตรวจจับวัตถุ **E18-D80NK** (ปรับระยะตรวจจับได้ 10-50 ซม.)
3.  **Computer:** สำหรับรันหน้าจอ GUI (รองรับ Windows / macOS)

### 🔌 การต่อสายวงจร (Wiring Diagram)
*   🟤 **สายสีน้ำตาล (VCC)** -> ต่อเข้าช่อง **5V** ของ Arduino
*   🔵 **สายสีน้ำเงิน (GND)** -> ต่อเข้าช่อง **GND** ของ Arduino
*   🟨 **สายสีดำ (Signal OUT)** -> ต่อเข้าช่อง **Digital Pin 2** (INT0) ของ Arduino *จำเป็นต้องพินนี้เพื่อใช้ External Interrupt*
